# Packages

Home Assistant packages, one per automation.

| File | Content |
|---|---|
| `spoolman_ams_sync.yaml` | on any AMS tray change: match the loaded filament to a Spoolman spool and set its location `AMS N` |
| `spoolman_deduct.yaml` | at print end: deduct the grams of each slot from the spool located there |
