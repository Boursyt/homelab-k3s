# Glance config

Glance dashboard, one file per block.

| File | Content |
|---|---|
| `glance.yml` | server, branding, custom CSS, 30 s auto-refresh, page include |
| `theme.yml` | Catppuccin Mocha |
| `homelab.yml` | page layout |
| `hardware.yml` | machines reachability |
| `k3s.yml` | cluster usage and nodes |
| `nas.yml` | NAS usage |
| `printer.yml` | 3D printer, AMS and low stock spools (Home Assistant, Spoolman) |
| `apps.yml` | user apps |
| `services.yml` | infrastructure services |
| `status.yml` | Gatus summary |
| `backups.yml` | last backups |
| `databases.yml` | Postgres and PgBouncer |
| `network.yml` | latency probes |
| `speedtest.yml` | internet speed (NAS and Pi) |
| `ingress.yml` | Traefik traffic |
